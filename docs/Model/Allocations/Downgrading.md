# Downgrading

**De-Syncing:** When downgrading from paid, all synced accounts are automatically removed and all investment accounts are automatically transferred from “Synced” to “Manual Mode.” All current progress is maintained from the last available sync.

**Other Notes:** All accounts otherwise retain their original form, and nothing is deleted. Syncing will not occur going forward, and any updates to position sizing will have to be manual. Recurring investments that were initiated in “Manual Mode” before syncing will have to be re-entered.
