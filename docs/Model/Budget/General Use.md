# General Use

**Editing Budget:** A user’s budgeting plan may be changed at any time by pressing the pencil icon at the top right of the “Breakdown” card on the “Budget” tab. Users may edit take-home income and expense data by tapping on the original values and entering a new number; entering a ‘0’ in any category will reset the value to zero, excluding it from the budget. To implement changes made to the budget, users must press the “Save Budget” button at the bottom of the page. Any changes made to the budget may be nullified by exiting out of the modal sheet through either swiping down or pressing the back arrow instead.

- Any material changes to the original values will create an updated “Investable Cash Flow,” which will affect the “Financial Framework” already created by the user, if applicable.

- A user may see reflected changes by navigating to the “Allocations” subtab in “Model” and tapping the “View Allocation Details” button. Any additional or depleted “Investable Cash Flow” dollars will be shown via a warning message on the Allocations sub-tab.
